# 🚀 Projeto Pixel Oracle

Pixel Oracle é um sistema de mentoria pré-lançamento para desenvolvedores indie: a partir de um pitch, mostra **o que jogadores elogiam e reclamam de forma recorrente** em jogos parecidos já lançados, com métricas, jogos-exemplo e citações reais de reviews da Steam. Não estima vendas ([[Mudanca de Foco do Projeto]]).
